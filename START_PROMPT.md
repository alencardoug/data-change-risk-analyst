# Prompt inicial para Codex ou Claude Code

Quero conduzir este projeto por **Spec-Driven Development investigativo** antes de implementar.

Primeiro:

1. leia `AGENTS.md`;
2. leia os arquivos na ordem definida nele;
3. confirme a fase atual e **não escreva código de produto**;
4. identifique quais decisões do starter são premissas aceitas e quais são apenas hipóteses;
5. identifique as ambiguidades de maior impacto para produto, arquitetura, portfólio e aprendizado.

Meu objetivo é duplo:

- construir um projeto corporativo pequeno, profissional na medida adequada para portfólio e processos seletivos;
- aprender LangChain e LangGraph de forma que eu consiga explicar e defender as decisões técnicas em entrevista.

Regras:

- não maximize quantidade de tecnologias;
- não transforme “usar LangGraph” em justificativa para nodes artificiais;
- não transforme “usar agent” em justificativa para autonomia desnecessária;
- não adicione RAG/embeddings/VectorDB;
- MCP é desejável, mas deve sobreviver à análise de custo/benefício;
- desafie score, routing, parallelization, storage e interface se houver alternativa mais simples;
- faça perguntas somente quando a resposta materialmente mudar a solução;
- para decisões técnicas reversíveis e de baixo impacto, proponha um default em vez de me interrogar;
- quando eu precisar aprender um conceito antes de decidir, explique-o brevemente e então faça a pergunta.

Conduza a sessão até estarmos prontos para o próximo comando adequado do Spec Kit. Não implemente ainda.
